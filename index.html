🛠️ Troubleshooting Basics

Most first-time hiccups come down to one of a few simple causes. Work through these in order before assuming something is broken.

  • Nothing happens when you double-click. The file may still be inside a compressed package. Right-click it and choose Extract All, then run the application from the new folder.
  • Windows blocks the application. A protection dialog may appear. Open the file's properties from a right-click and look for an option to allow it, then try again.
  • The launcher opens but the game does not appear. Close the launcher completely, reopen it, and wait a little longer. First runs can be slower than later ones.
  • You moved files around. Put the folder back the way it was, or download a fresh copy and start again in a new location.
  • Something still feels wrong. Delete the folder you downloaded, return to the releases page, and grab the current version once more. A clean start solves most mysteries.
